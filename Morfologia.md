# 🧬 Morfologia, Derivação e Flexão

Este documento reúne todas as regras de sufixos, prefixos, terminações gramaticais e conjugações que formam a espinha dorsal do vocabulário e da gramática da língua.

---

## 1. Terminações de Classes Gramaticais (Vogais Finais)
A vogal com a qual uma palavra termina define imediatamente a sua categoria na frase:

| Vogal  | Classe Gramatical / Categoria | Exemplo / Contexto                                |     |
| :----: | :---------------------------- | :------------------------------------------------ | --- |
| **-O** | **Substantivo**               | Nome de objetos, seres ou conceitos.              |     |
| **-A** | **Adjetivo**                  | Atributos e qualificadores.                       |     |
| **-I** | **Plural**                    | Marca o plural de substantivos e adjetivos.       |     |
| **-E** | **Verbo**                     | Palavras com função de ação ou estado.            |     |
| **-U** | **Primitivos da Natureza**    | Partes do corpo, elementos, natureza e fenômenos. |     |

---

## 2. Prefixo Derivacionais
Modificam o sentido base da raiz quando adicionados no início da palavra:

* **Des-** $\rightarrow$ **Reversão ou Oposição** (Ex: *Desinfectar* / inverter uma ação).
* **Bo-** $\rightarrow$ **Parentesco ou Relação Familiar** (Ex: *Pai* $\rightarrow$ *Bopai* = Sogro).

---

## 3. Sufixos Derivacionais
Adicionados ao radical para alterar a escala, função, local ou profissão:

* **-et-** $\rightarrow$ **Aumentativo** (Indica tamanho maior ou intensidade).
* **-eg-** $\rightarrow$ **Diminutivo** (Indica tamanho menor ou delicadeza).
* **-ey-** $\rightarrow$ **Lugar Destinado** (Ex: *Mokar* = Comer $\rightarrow$ *Mokeyas* = Cozinha / Local de comer).
* **-il-** $\rightarrow$ **Ferramenta ou Instrumento** (Objeto usado para realizar uma ação).
* **-ist-** $\rightarrow$ **Profissão ou Ocupação** (Indica o agente de um ofício).
* **-an-** $\rightarrow$ **Morador ou Nacionalidade** (Origem geográfica ou habitante de um local).

---

## 4. Conjugação Verbal
Os verbos sofrem flexão temporal e modal através de sufixos específicos atrelados à raiz:

| Sufixo | Tempo / Modo Verbal | Exemplo Prático |
| :---: | :--- | :--- |
| **-r-** | **Infinitivo** | A forma base do verbo (ex: *fazer*, *comer*). |
| **-as-** | **Presente** | Ação ocorrendo no momento. |
| **-is-** | **Passado** | Ação já concluída. |
| **-os-** | **Futuro** | Ação que ainda vai ocorrer. |
| **-us-** | **Condicional** | Hipóteses (ex: *Comeria*, *mataria*). |
| **-ru-** | **Imperativo** | Ordens, pedidos ou exortações. |
